# Makemore

This folder is reserved for my next project in Andrej Karpathy's **Neural Networks: Zero to Hero** playlist.

The goal is to build character-level language models that learn to generate names or other text-like sequences. I will add the notebooks, code, experiments, and detailed notes here as I work through the lessons.

## Planned topics

- Bigram language models.
- Character-level tokenization.
- Multilayer perceptrons for language modeling.
- Training, validation, and sampling.
- Deeper models and improved optimization.
- Batch normalization and related training ideas.
